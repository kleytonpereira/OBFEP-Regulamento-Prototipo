# Regulamento 2026 da OBFEP: recriação acessível (protótipo de pesquisa)

Página estática criada para pesquisa (Tópicos Avançados em Sistemas de Informação, UFC Quixadá, 2026.2). Não é o site oficial. O conteúdo pertence à OBFEP e foi copiado em 11/11/2026 de https://www1.fisica.org.br/~obfep/regulamento-2026/.

Gerada por script a partir da página original. Usada só para rodar ASES, WAVE e Lighthouse por URL.
